# 用户账号与资料表

## user_accounts 表

存储 Hoshi 管理员与普通用户的登录账号、密码哈希与状态信息。

**字段**

| 字段名 | 类型 | 约束(PK/FK/UNIQUE/NOT NULL/DEFAULT) | 说明（枚举须写全映射） |
| --- | --- | --- | --- |
| `id` | `BIGINT` | `PK, GENERATED BY DEFAULT AS IDENTITY` | 账号主键 |
| `username` | `VARCHAR(128)` | `UNIQUE, NOT NULL` | 登录用户名，按原值精确匹配，业务约定 3–32 位小写 ASCII 字母、数字或下划线 |
| `nickname` | `VARCHAR(256)` | `NOT NULL` | 账号显示名，允许重复，业务约定去首尾空白后为 1–32 个字符 |
| `password_hash` | `TEXT` | `NOT NULL` | `pwdlib` 生成的完整 Argon2 哈希字符串 |
| `account_type` | `VARCHAR(32)` | `NOT NULL` | 账号类型：`admin`=管理员账号，`user`=普通用户账号 |
| `role` | `VARCHAR(32)` | `NOT NULL` | 账号角色：`admin`=管理员角色（属于 `admin` 类型），`user`=普通用户角色（属于 `user` 类型） |
| `status` | `VARCHAR(32)` | `NOT NULL` | 账号状态：`active`=允许通过凭据核验，`disabled`=禁止登录 |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL, DEFAULT CURRENT_TIMESTAMP` | 创建时间（UTC） |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL, DEFAULT CURRENT_TIMESTAMP` | 更新时间（UTC），修改账号时更新 |

**索引**

| 索引名 | 类型 | 字段 | 理由（必须说明具体查询场景） |
| --- | --- | --- | --- |
| `pk_user_accounts` | 主键 | `id` | 按账号主键定位记录，供后续会话等业务表外键引用 |
| `uq_user_accounts_username` | 唯一 | `username` | 登录核验按用户名精确查询账号，同时保证全表用户名唯一 |

**关系**

当前表无外键关联，后续认证会话等业务表将通过外键引用 `user_accounts(id)`。

**建表 SQL**

```sql
CREATE TABLE user_accounts (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    username VARCHAR(128) NOT NULL,
    nickname VARCHAR(256) NOT NULL,
    password_hash TEXT NOT NULL,
    account_type VARCHAR(32) NOT NULL,
    role VARCHAR(32) NOT NULL,
    status VARCHAR(32) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT pk_user_accounts PRIMARY KEY (id),
    CONSTRAINT uq_user_accounts_username UNIQUE (username)
);
```
