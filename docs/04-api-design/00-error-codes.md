# 全局错误码

业务码为全大写字母和下划线组成的字符串。HTTP 状态与业务码分别承担协议结果和应用提示的职责，响应结构见[API 通用约定](00-conventions.md)。

## 通用码

| HTTP 状态 | 业务码 | 默认提示 | 用途 |
| --- | --- | --- | --- |
| 200 | SUCCESS | 响应成功 | 请求处理成功 |
| 400 | BAD_REQUEST | 请求参数有误 | 请求体无法解析、参数缺失或类型不匹配等请求错误 |
| 400 | PARAM_VALIDATION_FAILED | 参数校验未通过 | DTO、方法入参或约束校验失败，实际响应可使用一条具体校验提示 |
| 401 | UNAUTHORIZED | 请先登录 | 需要认证的请求 |
| 403 | FORBIDDEN | 无权执行此操作 | 当前身份没有操作权限 |
| 404 | NOT_FOUND | 请求的资源不存在 | 请求没有对应处理器或资源 |
| 405 | METHOD_NOT_ALLOWED | 请求方法不支持 | HTTP 方法不受目标资源支持 |
| 406 | NOT_ACCEPTABLE | 无法提供请求要求的响应格式 | Accept 要求的响应格式无法提供 |
| 409 | CONFLICTING_DATA | 数据冲突，请检查后重试 | 唯一键冲突，或业务明确判定的数据冲突 |
| 413 | CONTENT_TOO_LARGE | 请求内容过大 | 请求或上传内容超过允许大小 |
| 415 | UNSUPPORTED_MEDIA_TYPE | 请求内容类型不支持 | 请求 Content-Type 不受支持 |
| 429 | TOO_MANY_REQUESTS | 请求过于频繁，请稍后重试 | 请求频率超限 |
| 500 | INTERNAL_SERVER_ERROR | 服务器内部错误，请稍后重试 | 返回值校验失败或未专门映射的服务端异常 |
| 503 | SERVICE_UNAVAILABLE | 服务暂时不可用，请稍后重试 | 框架报告服务暂不可用，例如异步请求超时 |

框架异常保留原始 HTTP 状态和响应头。未单独列出的框架 4xx 异常使用 BAD_REQUEST，其他未单列错误使用 INTERNAL_SERVER_ERROR，HTTP 状态仍沿用框架原值。

以上代码的定义不代替认证、授权或限流组件的接入；相关组件接入时负责使用对应业务码。

## 模块业务码

具体业务模块在自己的码常量类中定义 `ApiCode`，命名遵循动词或形容词加名词的语义，并避免与其他业务码重复。业务码与接口行为经实现确认后，在本文补充状态、提示和用途。
