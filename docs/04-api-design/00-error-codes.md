# 全局错误码

客户端根据 HTTP 状态码和响应中的字符串 `code` 分支处理，`message` 用于展示。错误响应的 `data` 为 `null`。

公共 `ApiCode` 在 `internal/apicode` 中声明，每条声明包含 HTTP 状态码、字符串业务码和默认消息。业务模块用同一个类型在各自包中声明专属码，并在对应接口文档中列出。业务错误携带完整的 `ApiCode`，由 Gin 响应层直接写出。`4xx` 业务错误可以指定公开消息，未知错误使用 `INTERNAL_ERROR`。

| 状态码 | 错误码 | 默认消息 | 说明 |
| --- | --- | --- | --- |
| 400 | `INVALID_ARGUMENT` | 请求参数无效 | 请求参数格式或取值不符合接口约定 |
| 404 | `ROUTE_NOT_FOUND` | 请求路径不存在 | 请求路径未匹配到已注册路由 |
| 405 | `METHOD_NOT_ALLOWED` | 请求方法不受支持 | 路径存在，允许的方法由 `Allow` 响应头给出 |
| 500 | `INTERNAL_ERROR` | 服务器内部错误 | 服务端记录异常，客户端收到通用提示 |
